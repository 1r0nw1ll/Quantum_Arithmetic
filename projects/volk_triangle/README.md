# Volk–Grant QA Triangle

This module integrates the Volk–Grant Logarithmic Right Triangle (LRT) and toroidal mappings into the QA pipeline.

- QA triangle (C,F,G) from (b,e,d,a) where C=2ed, F=ba, G=(b^2+a^2)/2.
- See: qa_toroid_sumproduct.py for torus parameterization.
