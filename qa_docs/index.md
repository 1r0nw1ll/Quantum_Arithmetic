# QA Lab Documentation

Welcome to the QA Bob-iverse Autonomic Research Lab.

- Pipeline: scout → prioritize → plan → dispatch → executor → review → archive
- Collaboration: ZeroMQ bus with shared state and events
- Models: QALM (local), external agents (Codex, Gemini, OpenCode)

Getting started:
- make agent_loop — run a single orchestration loop
- make daemon — run continuously (set QA_DAEMON_INTERVAL)
- ./qa viz — generate visualizations and summaries

This index prevents duplicate “Initialize project documentation” tasks.
